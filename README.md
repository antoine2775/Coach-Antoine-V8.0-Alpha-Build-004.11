# Coach Antoine V8.0 Alpha — Build 004.10.2

**Devise :** Bouger quelques minutes, se sentir bien longtemps.

## Installation sous Windows

1. Décompressez le ZIP.
2. Ouvrez le dossier dans Visual Studio Code.
3. Ouvrez le terminal.
4. Tapez `npm install` puis `npm run dev`.
5. Ouvrez généralement http://localhost:5173/

## Inclus

- Splash screen et lunettes animées
- Riff original synthétisé par le navigateur
- Accueil, séance avec minuteur, progression
- Fin de séance sans confettis
- Carnet du Coach et secrets ZZ Top
- Réglages du son
- Navigation à cinq onglets

Le personnage est dessiné en SVG : aucun fichier image externe n'est nécessaire.
