# Installation pas à pas — Build 004

1. Faites un clic droit sur le ZIP et choisissez **Extraire tout**.
2. Ouvrez **Visual Studio Code**.
3. Cliquez sur **Fichier → Ouvrir un dossier**.
4. Choisissez `Coach-Antoine-V8.0-Alpha-Build-004`.
5. Cliquez sur **Terminal → Nouveau terminal**.
6. Tapez `npm install` puis appuyez sur Entrée.
7. Quand c'est terminé, tapez `npm run dev`.
8. Cliquez sur l'adresse affichée, normalement `http://localhost:5173/`.

## Page spéciale de test

Dans la barre d'adresse du navigateur, ouvrez :

`http://localhost:5173/presence`

Laissez cette page affichée environ une minute afin de juger si la respiration et les micro-mouvements restent suffisamment discrets.

Le Garage reste disponible sur :

`http://localhost:5173/garage`
