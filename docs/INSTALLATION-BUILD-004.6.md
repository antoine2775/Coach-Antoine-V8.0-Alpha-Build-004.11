# Installation — Build 004.6

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.6`.
5. **Terminal → Nouveau terminal**.
6. Taper `npm install`.
7. Puis `npm run dev`.
8. Ouvrir `http://localhost:5173/presence`.

Cette étape sert uniquement à contrôler les calques transparents.
Il n'y a volontairement pas encore d'animation.
