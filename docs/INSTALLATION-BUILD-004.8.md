# Installation — Build 004.8

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.8`.
5. **Terminal → Nouveau terminal**.
6. Taper `npm install`.
7. Puis `npm run dev`.
8. Ouvrir `http://localhost:5173/presence`.

Le mouvement du bras se déclenche toutes les 6,5 secondes sur la page de test.
Vous pouvez aussi cliquer sur **Tester le mouvement du bras**.

À vérifier :
- visage parfaitement fixe ;
- aucun morceau du visage ne suit le bras ;
- mouvement du bras très discret ;
- aucune animation des lunettes pour le moment.
