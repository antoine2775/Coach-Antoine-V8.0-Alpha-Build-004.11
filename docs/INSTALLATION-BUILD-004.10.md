# Installation — Build 004.10

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.10`.
5. **Terminal → Nouveau terminal**.
6. Taper `npm install`.
7. Puis `npm run dev`.
8. Ouvrir `http://localhost:5173/presence`.
9. Cliquer sur **Tester le geste complet**.

À vérifier : les lunettes doivent bouger avant le bras.
