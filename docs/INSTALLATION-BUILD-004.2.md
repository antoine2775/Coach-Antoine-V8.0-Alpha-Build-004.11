# Installation — Coach Antoine V8 Build 004.2

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.2`.
5. **Terminal → Nouveau terminal**.
6. Taper `npm install`.
7. Puis taper `npm run dev`.
8. Ouvrir `http://localhost:5173/`.
9. Pour comparer les 3 images V6.5 : `http://localhost:5173/presence`.

Cette version réutilise exactement les fichiers PNG originaux de la V6.5.
