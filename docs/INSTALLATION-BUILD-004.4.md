# Installation — Coach Antoine V8 Build 004.4

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. Cliquer **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.4`.
5. Cliquer **Terminal → Nouveau terminal**.
6. Taper :

```bash
npm install
```

7. Puis :

```bash
npm run dev
```

8. Ouvrir :

```text
http://localhost:5173/
```

9. Pour tester le geste des lunettes :

```text
http://localhost:5173/presence
```

Sur cette page uniquement, le geste revient toutes les 7 secondes.
Le bouton « Tester le geste maintenant » permet de le déclencher sans attendre.
