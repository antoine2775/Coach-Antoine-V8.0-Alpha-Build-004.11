# Installation — Build 004.9

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.9`.
5. **Terminal → Nouveau terminal**.
6. Taper `npm install`.
7. Puis `npm run dev`.
8. Ouvrir `http://localhost:5173/presence`.

Le test se répète toutes les 7 secondes.
Vous pouvez aussi cliquer sur **Tester le geste complet**.

À observer :
- visage totalement immobile ;
- lunettes qui glissent très légèrement sur le front ;
- main qui arrive ensuite ;
- lunettes qui remontent au moment où la main les atteint ;
- main qui revient.
