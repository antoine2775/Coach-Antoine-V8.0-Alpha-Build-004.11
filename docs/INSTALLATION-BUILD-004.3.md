# Installation — Coach Antoine V8 Build 004.3

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.3`.
5. **Terminal → Nouveau terminal**.
6. Taper :

```bash
npm install
```

7. Puis :

```bash
npm run dev
```

8. Ouvrir :

```text
http://localhost:5173/
```

9. Pour voir les trois avatars V6.5 :

```text
http://localhost:5173/presence
```
