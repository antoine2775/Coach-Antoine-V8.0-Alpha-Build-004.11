# Installation — Build 004.1

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.1`.
5. **Terminal → Nouveau terminal**.
6. Taper :

```bash
npm install
```

7. Puis :

```bash
npm run dev
```

8. Ouvrir l'adresse affichée, normalement :

```text
http://localhost:5173/
```

Pour le test spécial des lunettes :

```text
http://localhost:5173/presence
```

Laissez l'écran ouvert environ une minute. Le Coach doit rester immobile.
Seule la zone des lunettes peut bouger très légèrement.
