# Installation — Build 004.7

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.7`.
5. **Terminal → Nouveau terminal**.
6. Taper `npm install`.
7. Puis `npm run dev`.
8. Ouvrir `http://localhost:5173/presence`.

À vérifier :
- le visage reste parfaitement immobile ;
- le calque bras est bien séparé ;
- l'arrière-plan préparé ne doit pas introduire de morceau de visage artificiel.

Il n'y a volontairement toujours pas d'animation dans ce Build.
