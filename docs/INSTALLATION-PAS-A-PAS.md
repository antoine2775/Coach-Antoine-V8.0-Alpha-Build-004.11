# Installation pas à pas
1. Clic droit sur le ZIP puis **Extraire tout**.
2. Dans Visual Studio Code : **Fichier > Ouvrir un dossier**.
3. Choisir `Coach-Antoine-V8.0-Alpha-Build-003`.
4. Cliquer sur **Terminal > Nouveau terminal**.
5. Taper `npm install` puis Entrée.
6. Taper `npm run dev` puis Entrée.
7. Cliquer sur `http://localhost:5173/`.

Pour ouvrir le Garage du Coach : `http://localhost:5173/garage`.
