# Installation — Build 004.5

1. Clic droit sur le ZIP → **Extraire tout**.
2. Ouvrir **Visual Studio Code**.
3. **Fichier → Ouvrir un dossier**.
4. Choisir `Coach-Antoine-V8.0-Alpha-Build-004.5`.
5. **Terminal → Nouveau terminal**.
6. Taper `npm install`.
7. Puis taper `npm run dev`.
8. Ouvrir `http://localhost:5173/presence`.
9. Cliquer sur **Tester le geste maintenant** plusieurs fois.

À observer : la coupure autour de la zone mobile doit être beaucoup moins visible que dans Build 004.4.
